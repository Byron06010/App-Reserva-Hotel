# 🏨 Aplicación Hotelera - Sistema Web de Reservas

Aplicación web full-stack enferma para la gestión y reserva de vidas de hotel, construcción con tecnologías modernas de JavaScript, motor de plantas dinámicas y persistencia de datos en base de datos NoSQL.

El repositorio se encuentra organizado de la firma manual:

## 🚀 Tecnologías y Herramientas Utilizadas

* **Entorno de ejecución:** Nodo.js
* **Backend:** Expreso.js
* **Base de Datos:** MongoDB (NoSQL)[citar: 6]
* **Motor de Plantillas:** Manillar (Hbs) para el renderizado dinámico de vistas[citar: 6]
* **Control de versiones:** Git y GitHub

---

## 📁 Estructura del Proyecto

El repositorio se encuentra organizado de la firma manual:

* `src/` — Continúa la lógica del servicio, rutas, controladores y modelos de la aplicación.
* `img/` — Recursos gráficos, iconos e imágenes promocionales de las viviendas y el hotel.
* `paquete.json` (package.json) — Gestión de dependencias y scripts de ejecución del proyecto.
* `.env` / Configuración — Variables de entorno destinadas a la conexión con la base de datos.
